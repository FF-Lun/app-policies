## 常見問題 / FAQ

**我的筆記存在哪裡？ / Where are my notes stored?**
只存在你的裝置上（本 App 的資料夾），可在「檔案」App →「在我的 iPhone 上」→ MD Studio 看到。
Only on your device, in the app's folder (Files app → On My iPhone → MD Studio).

**需要網路嗎？ / Does it need internet?**
不需要。Python（含 numpy、pandas、scipy、matplotlib 等）已內建，完全離線運作。只有下載額外字型時才會連線。
No. Python (with numpy, pandas, scipy, matplotlib, …) is bundled and works fully offline. Network is used only when you download an extra font.

**如何開啟別處下載的 .md 檔？ / How do I open an .md file from elsewhere?**
在「檔案」App 長按檔案 →「分享」→ 選 MD Studio（可在「更多」裡固定到個人收藏）。
In the Files app, long-press the file → Share → MD Studio (you can pin it to Favorites under "More").

**Python 卡住了怎麼辦？ / Python seems stuck?**
按執行按鈕（變成紅色的「停止」）即可中止，下次執行會自動重新啟動 Python 環境。
Tap the run button (it turns into a red "Stop"). The Python environment restarts on the next run.

**圖表裡的日文／韓文變成方框？ / Japanese or Korean shows as boxes in charts?**
側邊欄「Python 圖表字型」可下載對應字型。
Download the matching font under "Python chart fonts" in the sidebar.
